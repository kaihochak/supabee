# Code of Conduct

## Our Standards

We are committed to a respectful, harassment-free community.

Examples of positive behavior:
- Being respectful and constructive
- Accepting feedback gracefully
- Focusing on what is best for the project and users

Examples of unacceptable behavior:
- Harassment, discrimination, or hate speech
- Personal attacks or trolling
- Publishing private information without permission

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, or code contributions that violate this Code of Conduct.

## Scope

This policy applies in project spaces and public interactions representing this project.

## Contact

To report concerns, open a private security-style report following `SECURITY.md` or contact the maintainers through repository security reporting channels.
